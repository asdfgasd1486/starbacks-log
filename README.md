# スタバ日記（starbacks-log）

行ったスターバックスの店舗・日付・頼んだもの・写真を記録する、スマホ向けのWebアプリです。
サーバーやビルドは不要で、HTML / CSS / JavaScript だけで動きます。

## できること

- **記録する**：行った日・店舗・頼んだもの（サイズ・カスタマイズ付き、複数可）・写真（複数可）・メモ
- **記録タブ**：すべての訪問を新しい順に月ごとに表示。各記録に「その店舗で何回目か」を表示
- **店舗タブ**：行った店舗の一覧
  - 並び替え：新着順／五十音順（あ行・か行…で見出し）／都道府県別／訪問回数順／初訪問が古い順
  - 都道府県で絞り込み、店舗名・よみがな・地名で検索
- **店舗の詳細**：訪問回数、初めて行った日、最後に行った日、過去に行った日すべて（年ごと）、各回の記録と写真
- **都道府県タブ**：47都道府県のうち行った県・店舗数・訪問回数を一覧
- **集計**：合計店舗数・合計訪問回数・訪問した都道府県数・今年の訪問回数
- **バックアップ**：写真ごと1つのファイルに保存・復元

## データの保存場所

記録と写真は、開いている**端末のブラウザ内（IndexedDB）**に保存されます。
別の端末とは共有されないため、機種変更などに備えて「設定」タブからときどきバックアップを保存してください。
写真は保存時に自動で縮小（長辺1600px・JPEG）されます。

## 公開方法（GitHub Pages）

1. このブランチを `main` にマージ
2. リポジトリの Settings → Pages → Build and deployment の Source を **GitHub Actions** にする
3. `main` へのpushで自動的に `https://<ユーザー名>.github.io/starbacks-log/` に公開されます

スマホ（iPhone の Safari）で開き、共有ボタン →「ホーム画面に追加」するとアプリのように使えます。

## ローカルで試す

```sh
python3 -m http.server 8000
# http://localhost:8000 を開く
```
